PATCH 30.3.0B - Paper market-data fallback and replay mode

Scope:
- Add paper-only local OHLCV cache loader for cached/replayed candle windows.
- Add `--market-data-mode live|auto|cache|replay` to the paper runner.
- Keep `live` as the default behavior; `auto` tries the exchange first and falls back to local replay cache when live fetch fails.
- Record market-data source events in `paper_events.jsonl` and paper status.
- Add regression coverage for local cache normalization, replay offset advancement, and runner wiring.
